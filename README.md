# О проекте 💻
WeatherApp — приложение для просмотра прогноза погоды. 

# Стек ⚙️
- HTML
- CSS
- JavaScript
- ReactJS

# Ключевые особенности ⚡️
- Взаимодействие с [openstreetmap](https://nominatim.openstreetmap.org) и [openweathermap](https://openweathermap.org) API
- Предзагрузка данных о погоде в поиске
- Поддержка темной и светлой темы
- Кеширование данных для минимизации запросов к API
- Минималистичный интерфейс

# Установка и запуск 🛠️

### ❗️ Вставьте свой ключ в .env файл (бесплатный ключ можно сгенерировать [тут](https://home.openweathermap.org/api_keys))

### Установка зависимостей

```
npm install
```

### Запуск в режиме разработки

```
npm start
```

### Сборка

```
npm run build
```
